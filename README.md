# Requests checker (Web audit Module)

Provides a web-audit module to check requests cache and performance.


## Install
1. Install with your favorite package manager
2. Add the module in your web-audit.config.js 
```
export const config = {
	modules: [
        ...
        'node_modules/web-audit-module-requests-checker/src/modules/RequestsCheckerModule.js',
    ],
},
```
